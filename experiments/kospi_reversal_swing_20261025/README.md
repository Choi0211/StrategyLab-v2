# KOSPI 대형주 과매도 반등 — 실데이터 독립 연구 (2026-10-25)

**결론: 과거 백테스트는 일부 플러스지만 체결 민감도가 높아 실거래 승격 금지(NO-GO).**

## 입력 데이터 및 모델

- 2014~2026년 FinanceData/marcap KRX 일별 종목 시세 13개 파일(약 266MB), 네이버 금융 KOSPI 지수 3142일. 모두 실제 공개 시계열이고 이 저장소에는 입력 원본을 올리지 않음.
- 2015-01-02~2026-10-23 백테스트, 2022-01~2026-10-23 분리 검증, 초기자산 1000만원.
- **당시** 코스피 시총 상위 150개 보통주(종목코드 끝자리 0 기준 + ETF/ETN/스팩/리츠 명칭 제외: 완전한 분류는 아님) 중 과거 20거래일 평균 거래대금 100억원 이상.
- 코스피 종가 > 200일선, 종목 종가 > 200일선, 최근 5거래일 수익률 -7% 이하, Wilder RSI(2) < 10.
- 지정가: 신호 다음 날 전일 종가의 99% 매수 지정가, 하루 유효. 다음날 5일선 회복/종가 기준 -8%/진입 후 7거래일 경과시 익일 시가 매도. 최대 5종목, 진입시 당시 자산 20% 배정.
- 분할/병합 감지 이후 200 종목 거래일 신규 진입 배제. 매매 로직은 연구용 계산이며 실제 서비스와 완전히 분리되어 있음.

## 거래비용 및 신뢰도 한계

- 매수·매도 증권사 수수료 각 0.015% 가정.
- 코스피 매도세(농특세 포함) 날짜별: 2019-06-02까지 0.30%, 2020년까지 0.25%, 2021~22년 0.23%, 2023년 0.20%, 2024년 0.18%, 2025년 0.15%, 2026년 0.20%. 근거: 국회예산정책처 2026 대한민국 조세 / 재정경제부 2026년부터 이렇게 달라집니다.
- marcap 가격은 기업행동 수정주가 보장 안 됨. 분할 배제 휴리스틱은 합병·증자·배당·상장폐지·정지를 완벽히 보정하지 못함. 날짜별 시총 구성으로 현재 생존종목 고정 편향을 줄였지만 모든 생존편향이 사라지지는 않음.
- 실제 지정가 대기열/가격호가 단계/부분체결/장중 슬리피지·시장 충격을 알 수 없음. 종목별 일봉의 저가가 지정가에 닿았다고 체결을 보장하지 않음.
- 모델별 체결 및 보유 종목 구성이 다르므로 진입가 비교는 통제된 동일 체결 표본 실험이 아님.
- 2022년 이후는 시간을 나눠 계산했지만, 이 전략을 연구하면서 원칙을 확인한 구간이므로 진정한 사전등록 홀드아웃 실험이나 미래 검증을 대체하지 못함.
- 결과는 배당 제외 주가 기반, 투자 권유 아님. API 주문·모의매매·실거래·챔피언 승격·서비스 코드 변경 없음.

## 2026-10-25 후속 연구 — 호가단위, 기업행동, 자금 배분

**아래 수치는 실제 일별 가격을 사용하는 모델링 결과이며, 실제 체결·실전 수익이 아닙니다.**

### KRX 호가단위 반영

- 2023-01-25 이전 코스피와 이후 가격대별 호가단위를 개별 적용. 출처: [한국거래소 호가가격단위](https://regulation.krx.co.kr/contents/RGL/03/03010100/RGL03010100T3.jsp), [2023년 호가단위 변경 안내 - 유안타증권](https://www.myasset.com/myasset/customer/notice/CU_0201000_P2.cmd?SEQ=202301160940590000000004&gubun=norNotice).
- 전일 종가 × 0.99 매수 지정가를 해당 거래일 유효한 호가단위 아래로 내림 처리. 잘못된 소수 호가로 체결하지 않음.
- 보수적 지정가 C의 2022~2026 수익률은 **기존 +22.77% → 유효 호가 적용 +22.62%**, MDD **-28.44% → -26.68%**, 거래건수 **414 → 409건**.
- 유효 호가에 체결 깊이 0.5% 요구 시 **-1.96%**, 매수 추가 비용 0.3%·매도 불리한 체결 0.3%에서는 **-11.40%**.
- 호가단위 자체보다 주문 대기열·슬리피지 가정이 더 큰 변동 원인. 0.2% 관통해도 실제 체결 보장 아님.

### 기업행동 관측 검사

- 별도 스크립트에서 805건의 기본 보수적 모델 청산 거래 보유 구간 일별 상장주식수·주가 변동을 전수 대조.
- 보유 중 상장주식수 25% 초과 변동 또는 하루 주가비 1.5 초과/0.6 미만을 보인 구간 **1건** 확인: 2015-08-03 현대엘리베이, 주식수 비율 1.2547, 종가 비율 1.0025, 모델 해당 거래 수익 +0.746%.
